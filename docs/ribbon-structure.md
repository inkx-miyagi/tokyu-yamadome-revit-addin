# リボンタブ・パネル・コマンド構成案

## 基本方針

- 暫定リボンタブ名は「生産技術部」とする。
- 将来的な名称変更を前提に、コード上はタブ名を定数化する。
- 初回設定系と日常操作系を分離する。
- 現行OrkestraのDynamo実行ボタン群を、Revit標準コマンドとして使いやすい業務フロー順に再整理する。
- 配置順は「設定、表示、作成、調整、図面化、集計」を基本とする。
- 利用頻度が高い機能、または業務の起点になる機能は大ボタンとする。

## タブ名

| 項目 | 名称 |
|---|---|
| 暫定タブ名 | 生産技術部 |
| 候補 | 山留め支援、山留め、山留めツール、山留め施工支援 |

## UI上の補足

- 初期設定は日常操作パネルに混ぜず、左端に独立配置する。
- 「表示設定」は作業前後で頻繁に使うため、初期設定の次に配置する。
- 「掘削」「山留め部材」は主要作成フローとして大ボタン中心にする。
- 「部材調整」は作成後に使うため、作成系パネルの右側に配置する。
- 「図面化」「集計」は成果物作成系として右側に配置する。
