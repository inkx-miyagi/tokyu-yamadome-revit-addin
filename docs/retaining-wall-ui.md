# 山留め壁作成 UI暫定案

## 目的

「山留め壁作成」は作成条件が多く、実行前の確認と入力補助が必要になるため、WPF画面を前提とする。

現時点では実処理へ接続せず、リボンから起動できる暫定UIとして作成する。

## 暫定入力項目

| 区分 | 項目 | 内容 |
|---|---|---|
| 入力条件 | 入力元 | 選択中のモデル線分、掘削ライン、閉じた線分ループ、Excel仕様 |
| 入力条件 | 壁種 | SMW、親杭横矢板、鋼矢板、地中連続壁、任意壁タイプ |
| 入力条件 | ファミリタイプ | 山留め壁作成に使用するRevitファミリタイプ |
| 高さ条件 | 上端レベル | GL、1FL、設計GLなど |
| 高さ条件 | 上端オフセット | mm単位 |
| 高さ条件 | 下端レベル | 根伐り底、B1FL、B2FLなど |
| 高さ条件 | 下端オフセット | mm単位 |
| 仕様 | 仕様入力 | 初期設定のExcel仕様、または将来的な直接指定 |
| オプション | 既存壁更新 | 同名/同一線上の既存山留め壁を更新対象にする |
| オプション | ファミリ不足警告 | 必要ファミリが見つからない場合に警告する |
| オプション | 表示設定適用 | 作成後に表示設定を適用する |
| 事前チェック | チェック結果 | 選択、ファミリ、レベル、Excel仕様の確認結果を表示予定 |

## 今後の実装候補

- Revitモデル内のレベル一覧をComboBoxへ反映する。
- 山留め壁ファミリタイプ一覧をComboBoxへ反映する。
- 選択中のモデル線分、掘削ライン、閉じた線分ループを事前チェックする。
- 初期設定で保存したExcel仕様パスを表示・参照できるようにする。
- 実行前に作成対象数、更新対象数、警告件数を表示する。
- 作成処理はTransactionGroupでまとめ、失敗時にロールバックできるようにする。
